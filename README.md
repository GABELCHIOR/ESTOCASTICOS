# Processos Estocásticos

Material de estudo em trilha, capítulo por capítulo, baseado em Sheldon M. Ross,
*Introduction to Probability Models*, 13ª edição.

Mesmos assuntos e mesma notação do livro; explicação, exemplos, ordem e exercícios
refeitos para estudar sozinho e para a prova, com simulações interativas, atividades
em cada passo, demonstrações recolhíveis e questões com feedback.

Prontos: **capítulo 5** (a exponencial e o processo de Poisson) e
**capítulo 6** (cadeias de Markov em tempo contínuo).

Abra `index.html` ou acesse pelo GitHub Pages.
